# Dockside v0.1.0-alpha.1

This is the first public alpha of Dockside.GG Game Panel: a Discord-first,
Docker-native control plane for self-hosted game servers.

> [!CAUTION]
> This release is for testing and evaluation. It is not recommended for
> production use. Use a disposable host and maintain independent backups of all
> panel and game data. Storage formats, configuration, and APIs may change in a
> later `0.x` release.

## Highlights

- Discord OAuth2 authentication, expiring single-use invitations, optional MFA
  enforcement, and panel-wide or per-server permissions.
- Docker-isolated game servers with provisioning, start, stop, restart, kill,
  crash recovery, resource limits, and real-time telemetry.
- Installation/runtime console streaming with stdin, RCON, and template-defined
  REST command transports.
- File manager, drag-and-drop uploads, text editing, folder downloads, backups,
  retention, restore, and schedules.
- Named Discord webhooks for selected server events and optional backup ZIP
  delivery to a Discord channel.
- Offline, release-bundled Pelican- and Pterodactyl-compatible template
  snapshots plus the independently synchronized Dockside-native catalog.
- Visual and raw-JSON Dockside template editing, import/export, immutable
  versions, and server-to-template creation.
- Guided Windows and Linux installers for local, existing-proxy, and direct
  HTTPS deployments.
- Owner-only version display and update checks for future Dockside releases,
  with verified release archives, a rotating full pre-update recovery snapshot,
  health-gated worker startup, and automatic rollback.

## Install

Download `dockside-game-panel-0.1.0-alpha.1.zip` on Windows or
`dockside-game-panel-0.1.0-alpha.1.tar.gz` on Linux from this release. Do not
use GitHub's automatically generated source archive for a release installation.

Verify the download against `SHA256SUMS`, extract it, and run:

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

Linux:

```bash
chmod +x scripts/*.sh
./scripts/install.sh
```

The guided installer requires a Discord application client ID and client
secret. It prints the exact OAuth callback URI to add in the Discord Developer
Portal.

## Known limitations

- Dockside manages only the Docker host on which the panel is installed. Remote
  node agents are intentionally outside the current architecture.
- Windows support uses Docker Desktop with Linux containers. Host telemetry
  represents the Docker Linux environment rather than every Windows process.
- Discord backup delivery is limited by Discord attachment and retention rules
  and is not a replacement for independent backups.
- The Dockside-native public catalog requires outbound HTTPS to synchronize.
  Bundled Pelican/Pterodactyl compatibility templates remain available offline.
- This is the first release, so there is no earlier Dockside version from which
  to upgrade. The updater is included so this alpha can move to the next
  supported release; the released base database migration becomes the forward
  upgrade boundary for later versions.
- Alpha releases may include documented breaking changes before `1.0.0`.

## Reporting problems

Use the repository's structured issue forms and include the Dockside version,
host OS, Docker/Compose versions, reproduction steps, and sanitized diagnostics.
Never include `.env`, Discord secrets, webhook URLs, tokens, private backups, or
game-server credentials.

See the full [installation](../INSTALLATION.md), [operations](../OPERATIONS.md),
[template](../TEMPLATES.md), and [security](../SECURITY.md) documentation.
